Skills

A small, curated capability layer. Skills are screened deterministically before they ever reach the model, and only trusted, reviewed entries are recommended — no open marketplace, no supply-chain surprises.

Curation in progress

No recommended skills are listed yet. We would rather show an honest empty shelf than fill it with names we cannot vouch for. Recommendations land here one by one as they pass review.

Propose a skill on GitHub Issues
1

Submit

Publish your skill repository on GitHub and open an issue with the link and a short description of what it does.

▸
2

Review

We read the code: permissions, network behaviour, data handling. Skills must pass the deterministic router checks and our security review.

▸
3

Listed

Approved skills appear in the recommended shelf above and mount into your local install — read-only sources, revocable at any time.

Models & Transparency

We will publish how this product actually runs — which models serve it and how much compute it consumes. No estimates, no marketing charts: only what the software itself reports.

COMING ONLINE — statistics service not yet live

The aggregation service is being built. Until it ships, this page shows the pipeline design — and nothing else. Any number here before launch would be a lie, so there are none.
