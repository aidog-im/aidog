01

Get Started

Three steps from a clone to a running local console: fetch the repository, run the one-command installer, then fill the slots in the guided wizard.

1

Get the repository

I'm AiDog ships from a private repository — clone access required.

git clone <product-repo-url> aidog && cd aidog
▸
2

Run the installer

One command: provision + boot + verify. The installer is idempotent, so re-running it is always safe.

bash deploy/install.sh
▸
3

Fill the slots

The guided wizard prompts for every credential — hidden input on a terminal, values never echoed; output names slots and lengths only.

aidog setup

Public download & hosted docs land with the public release.

02

Skills

A small, curated capability layer. Skills are screened deterministically before they ever reach the model, and only trusted, reviewed entries are recommended — no open marketplace, no supply-chain surprises.

No recommended skills are listed yet. We would rather show an honest empty shelf than fill it with names we cannot vouch for. Recommendations land here one by one as they pass review.

3

05

Security & Trust

Local-first by construction — the quiet guarantees, stated plainly.

Loopback by default

Services listen on 127.0.0.1 only — reachable from your machine, not from your network.

Credentials stay local

Secrets live in one gitignored file (mode 0600). Output and logs report slot names and lengths — never values.

Writes need your token

Every console write operation requires your local access token.

Telemetry off by default

Usage tallies on your machine. Nothing leaves it unless you opt in.

en + zh interface, English source

The interface speaks English and Chinese; all source code is written in English.

Free forever

Permanently free — no paid tier, no in-app purchase, no usage fee, ever.
