Local console not found

This desktop shell needs a local I'm AiDog install to talk to. It could not find the local web console (web/server.py).

To fix this:

1. Set the AIDOG_REPO environment variable to the path of your I'm AiDog install directory, then restart the shell.
2. Or start the shell from inside the install directory (or its parent).

No console was started and nothing was modified. Once an install is found, this window loads the local console instead.
